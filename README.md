# cloudhost-adminwebsite

A full-stack web application to host, manage, and deploy Discord bots. Features include user authentication, bot upload/management, and Docker-based bot isolation.

## Structure
- `client/`: React frontend
- `server/`: Node.js/Express backend
- `bots/`: Directory for user-uploaded Discord bots

## Features
- User authentication (sign up, login, logout)
- Upload, manage, and deploy Discord bots
- Start/stop bots in isolated Docker containers
- View bot logs
